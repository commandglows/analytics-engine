# Analytics preview

Synthetic native Flutter preview. No provider, visitor data or publishing action.

## Run

Use Doppler and the ShipGlows managed flutter run loop. The declared backend is
none because every card and action is synthetic. Read ENVIRONMENT.md and the
live registry for the assigned preview URL.
