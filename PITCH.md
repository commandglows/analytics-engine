# Analytics Engine — Pitch

> Pitch reviewed: 2026-10-15 · Project state: see canonical sources below

Analytics Engine is a shared Flutter package and agent CLI that displays attributed analytics opportunities, hypotheses and proposed review actions for ContentGlows and ShipGlows. It is for the host products that consume it and for the operators who review evidence before acting on it.

## Current state

A Flutter package, a synthetic demo, sync tooling and a Python CLI exist, while live API authentication and deployed routes are documented as unverified.
